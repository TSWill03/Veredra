# CTS text integration and progressive reader — QA 0.1.6+8

CTS is an independent text runtime. Veredra bundles the MIT source of CTS API v1 from commit 2a14b6c8; assets/cts/SOURCE.json pins its exact SHA-256. Update the vendored source only from a reviewed CTS commit and rerun the bundle/worker tests. No audio code or model weights are included.

- Desktop uses a Python worker and installed Argos pairs; select CTS CPU batch 512, CUDA 512, CUDA 1024 or CUDA 512 beam 2. Legacy modes remain for old checkpoints. CUDA failure during initialization explicitly switches to CPU before any chapter; mid-job errors stop the job. Effective backend/runtime and model participate in checkpoint identity.
- Python emits chapter-ready only after an atomic, checksummed checkpoint. Dart verifies the file hash and loads the selected chapter. Progressive reader supports previous/next, jump, scroll, font size, pause. The final managed book is registered after all selected chapters finish; opening it passes chapter index and relative position to the normal reader. Incomplete checkpoints remain local. Paused sessions resume translation checkpoints, not preview scroll position. No annotations/marks in the temporary reader.
- Web/iOS/Android retain existing consented book sync. They do not run Python/CUDA or hosted CTS jobs. No text upload is added. No audio work.
- VEREDRA_PYTHON selects an absolute local Python executable; CTS_CUDA_DLL_DIRS points to trusted local NVIDIA DLL directories. A QA build with VEREDRA_QA_DATA_ROOT uses a separate absolute documents directory, disables Supabase and updates. Never point QA at real documents.
- Destruking real benchmark: Argos 1.11.0 + CT2 4.9.0, RTX 3050 Ti, three EN->PT private chapters: serial 50.746 s; CPU512 30.560 s; CUDA512 7.744 s; CUDA1024 6.458 s; CUDA512 beam2 6.919 s. 23 cases across EN->PT and PT->EN, five profiles, 115/115 nonempty outputs. Single warmed run; no production throughput guarantee or human quality approval. Numeric/named-entity alerts remain. Private outputs outside Git.
- Test via python tool/test_argos_bridge.py and python tool/smoke_cts_bridge.py --profile cuda --batch 1024. Real GPU interruption/resume, checkpoint and CPU fallback passed. Flutter progressive reader test reads while worker pending.
- Release gates: human quality review, representative repeated runs, glossary/names, platform and sync acceptance. Do not publish QA build.
